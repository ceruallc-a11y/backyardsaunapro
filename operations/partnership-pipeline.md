# Partnership Pipeline

## Stages

`research` -> `qualified` -> `owner_approved_for_outreach` -> `contacted` -> `discovery` -> `proposal_draft` -> `proposal_approved` -> `negotiation` -> `contracted` -> `active` -> `reporting` -> `renewal_review`

Closed states: `not_a_fit`, `declined`, `paused`, `expired`.

## Entry criteria

- `qualified`: real company, relevant buyer overlap, source URLs recorded, no known editorial conflict.
- `owner_approved_for_outreach`: owner approves the exact prospect and channel.
- `contacted`: message was sent manually and timestamp recorded.
- `proposal_approved`: scope, price, placement, disclosure, term, deliverables, measurement, revision rights, and cancellation terms reviewed.
- `active`: signed agreement and payment requirements satisfied.

## Weekly review

1. Reconcile active obligations before proposing new placements.
2. Review prospects with overdue next actions.
3. Verify any metrics intended for outreach.
4. Check conflicts with current partners, especially protected placements.
5. Record replies and next actions.
6. Do not send messages during the review automatically.
